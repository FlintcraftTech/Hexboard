# [HASH] — PolyForm Noncommercial 1.0.0 added as LICENSE, with a plain-English licence section in a new README

The licence choice was settled at the previous planning session; this build only put it in place. The intent it serves is a purpose-limited derivative right — people may read the source and fork it to build Hexboard in another language, but get no general right to copy it — and nothing off-the-shelf grants exactly that. PolyForm Noncommercial is the closest fit: a hobbyist building a German Hexboard is squarely permitted, anyone selling Hexboard is not, and unlike a custom licence it is plain-language, lawyer-drafted and recognised.

The licence text was fetched from the PolyForm project's own official plain text rather than reproduced from memory, and then checked byte-for-byte against what was fetched. That check is worth naming: a licence reproduced from memory can be subtly wrong in ways nobody notices until it matters, and the whole value of using a standard licence is that it is the standard text. The file carries a `Required Notice: Copyright Alex Wilder` line above the licence, which is the mechanism the licence's own Notices clause defines for naming the licensor.

The README was kept deliberately minimal — a title, one line of description, and the licence section this item called for. A proper public-facing README is separate queued work ([public-readme]), so building one here would have pre-empted it. The licence section states the terms in plain English and says outright that source-available is not the same as open source, because that distinction is the one a visitor is most likely to get wrong.

The gap accepted at planning still stands: the licence also permits noncommercial forks that were not the intent, so a free rival keyboard could be built on this code. That was judged acceptable because the realistic threat is commercial appropriation.
